Campo de búsqueda de 40px con icono y texto de ayuda.

**Props:** `placeholder` (string): Texto de ayuda; `value` (string): Texto escrito (reemplaza la ayuda); `icon` (string): Icono; `search` por defecto.
**Cuándo:** Arriba de una lista o del panel de nodos para filtrar.
**Evitar:** Más de un campo de búsqueda por panel.
