Menú lateral amplio: cabecera con título y subtítulo, filas grandes con icono; la activa lleva una barra naranja.

**Props:** `title` (string): Nombre principal; `subtitle` (string): Segunda línea atenuada; `logo` (string): Icono del logo; `items` ({ icon, label, active? }[]): Filas del menú.
**Cuándo:** Menú de una app con 3–5 secciones grandes, pantallas táctiles o kioscos.
**Evitar:** Más de 6 filas; iconos de distinto estilo.
