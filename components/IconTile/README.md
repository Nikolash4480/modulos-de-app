Cuadro de esquinas `radius-sm` que aloja un icono; abre filas de lista, nodos y tarjetas.

**Props:** `icon` (string): Nombre del icono; `tone` ('neutral' | 'green' | 'accent' | 'dark' | 'amber' | 'night'): Color del cuadro; `size` (number): Lado en px; 32 por defecto; `round` (boolean): Forma circular.
**Cuándo:** A la izquierda de un título de lista o de nodo. `green` para el elemento activo, `dark` para acciones del flujo, `accent` para destacar uno.
**Evitar:** Usarlo como botón (no tiene estados); mezclar más de dos tonos en la misma lista.
