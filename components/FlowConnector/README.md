Línea de conexión vertical con etiqueta centrada y rama horizontal opcional.

**Props:** `height` (number): Alto en px; 44 por defecto; `label` (string): Etiqueta centrada (Sí); `branch` ({ label, width? }): Rama horizontal hacia la derecha con su etiqueta.
**Cuándo:** Entre nodos; `branch` bajo una condición para el camino alternativo.
**Evitar:** Etiquetas largas; conectores sin nodos a ambos lados.
