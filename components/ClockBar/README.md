Barra redondeada con logo, fecha en dos líneas, hora grande, separador, usuario y chips de estado.

**Props:** `date` (string): Día; `sub` (string): Fecha; `time` (string): Hora; `user` (string): Nombre del usuario; `pills` ({ label, tone? }[]): Chips de estado a la derecha; `logo` (string): Icono del logo.
**Cuándo:** Cabecera de una pantalla de turno o terminal.
**Evitar:** Más de dos chips; segundos en la hora.
