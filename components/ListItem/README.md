Fila de lista con tile de icono, título, subtítulo y marcador de favorito opcional.

**Props:** `icon` (string): Icono del tile; `tone` (IconTile tone): Color del tile; `title` (string): Título; `subtitle` (string): Descripción corta; `starred` (boolean): Si está definido, muestra la estrella (rellena si es true).
**Cuándo:** Catálogo de bloques o nodos que se arrastran al lienzo.
**Evitar:** Subtítulos de más de una línea; más de una acción por fila.
