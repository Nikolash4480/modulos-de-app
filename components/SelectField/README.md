Selector de 40px con icono, valor y flecha, sobre fondo suave.

**Props:** `value` (string): Valor mostrado; `icon` (string | false): Icono; `folder` por defecto, `false` lo quita.
**Cuándo:** Elegir proyecto, carpeta o borrador al inicio de un panel lateral.
**Evitar:** Listas largas dentro del selector sin búsqueda.
