Barra segmentada en ticks verticales; los primeros según el valor se llenan de naranja.

**Props:** `value` (number): Porcentaje 0–100; `ticks` (number): Cantidad de ticks; 32 por defecto; `height` (number): Alto en px; 28 por defecto.
**Cuándo:** Un porcentaje que se lee de un vistazo dentro de `StatCard`.
**Evitar:** Valores que necesitan precisión; menos de 20 ticks.
