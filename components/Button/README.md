Botón de 36px (o 28px `sm`) con icono opcional a cada lado.

**Props:** `variant` ('primary' | 'dark' | 'outline' | 'soft' | 'ghost'): Estilo; `primary` por defecto; `size` ('md' | 'sm'): Alto 36 o 28px; `icon` (string): Icono a la izquierda; `iconRight` (string): Icono a la derecha; `children` (ReactNode): Texto.
**Cuándo:** `primary` para la acción principal (una por pantalla), `outline` para “Detalles”, `soft` para “Enviar” dentro de un campo.
**Evitar:** Dos botones `primary` en la misma vista; texto blanco sobre naranja.
