Marco de teléfono de ancho libre con barra de estado (hora, señal, wifi, batería) y cuerpo en columna.

**Props:** `width` (number): Ancho en px; 340 por defecto; `time` (string): Hora; “9:41” por defecto; `tabs` ({ icon, label, active? }[]): Barra de pestañas inferior (opcional, 2–5); `children` (ReactNode): Contenido.
**Cuándo:** Presentar una pantalla móvil dentro de una lámina o maqueta.
**Evitar:** Usarlo como contenedor de pantalla de escritorio.
