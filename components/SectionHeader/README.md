Encabezado plegable de una sección: título, contador y flecha.

**Props:** `title` (string): Título; `count` (number): Contador a la derecha; `open` (boolean): Flecha hacia arriba cuando está abierta.
**Cuándo:** Agrupar listas largas de nodos o ajustes en un panel lateral.
**Evitar:** Más de tres niveles; secciones sin contador cuando la lista cambia.
