Avatar de una inicial, cuadrado (`radius-xs`) o circular.

**Props:** `label` (string): Inicial o dos letras; `size` (number): Lado en px; 24 por defecto; `round` (boolean): Forma circular; `tone` ('neutral' | 'night' | 'tile'): Color.
**Cuándo:** Autores de comentarios, personas con las que se comparte un archivo, usuario en la barra lateral.
**Evitar:** Fotos reales dentro de este componente; más de dos letras.
